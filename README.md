# Vinheria Agnello — Checkpoint 03

## Descrição

Sistema de gestão de estoque desenvolvido em JavaScript para a Vinheria Agnello. O projeto utiliza:
- Objetos e arrays para armazenar informações dos vinhos (nome, tipo, safra e estoque).
- Funções de alta ordem para manipular esses dados: `forEach` para listar o acervo completo, `filter` para identificar vinhos com estoque baixo, `reduce` para calcular o total de garrafas e `map` para exibir os nomes em caixa alta. 
- Todos os resultados são exibidos via `console.log` e `alert()`.
